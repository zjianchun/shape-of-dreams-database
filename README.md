# Shape of Dreams — Open Game Database & Theorycrafting Kit (v1.4)

[![Official Companion](https://img.shields.io/badge/Companion-shapeofdreams.wiki-blue?style=flat-square)](https://shapeofdreams.wiki/)
[![Patch](https://img.shields.io/badge/Patch-v1.4%20Starless%20Path-purple?style=flat-square)](https://shapeofdreams.wiki/guides/shape-of-dreams-patch-notes/)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

An open-source, machine-readable compendium and calculation dataset for **Shape of Dreams** (Steam App ID: 2444750), an action roguelite developed by Lizard Smoothie and published by NEOWIZ.

All stats, cooldown formulas, and synergy modifiers are verified against the shipped v1.4 *Starless Path* game client.

---

## 🌟 Interactive Live Companion

For interactive, real-time calculations without installing local scripts, visit the live web tools:
- 🛠️ **[Dream Weaver Build Planner & Stat Architect](https://shapeofdreams.wiki/builds/)** — Real-time cooldown, damage multipliers, and shareable build URLs.
- 📖 **[Complete 578-Entity Database Compendium](https://shapeofdreams.wiki/database/)** — Instant client-side search across all 9 Travelers, 132 Memories, 93 Essences, 259 Way of Stars nodes, and 85 Achievements.
- 🎯 **[v1.4 Builds & Tier List Guide](https://shapeofdreams.wiki/guides/shape-of-dreams-builds/)** — Cetus freeze burst, Shell reflect, and Vesper blitz loadouts.
